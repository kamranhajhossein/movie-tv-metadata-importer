Import movie and TV series metadata, IMDb ratings and posters from OMDb into any WordPress post type using an IMDb ID.

== Description ==

Movie & TV Metadata Importer for OMDb is a lightweight, theme-independent WordPress movie importer. It stores portable WordPress post meta and does not require ACF or a movie theme.

Features include IMDb ID import, metadata preview, movie and series details, IMDb ratings, poster sideloading, selectable post types and developer filters.

== Installation ==

1. Upload and activate the plugin.
2. Open Settings > Movie & TV Importer.
3. Enter an OMDb API key and select post types.
4. Edit a post and import using an IMDb ID.

== Frequently Asked Questions ==

= Does it require ACF or a specific movie theme? =

No. It uses standard WordPress post meta and works independently.

= Does it support custom post types? =

Yes. Any public post type with an admin editor can be enabled in settings.

= Is the API key exposed in the browser? =

No. OMDb requests run on the WordPress server.
